## Selected work

### 01 · Federated Credit Risk Assessment

A privacy-preserving federated-learning system for loan-default prediction using **FedAvg**, with centralized baselines and IID / Non-IID evaluation.

- **Result:** ~**76.5% accuracy** after **15 communication rounds** under IID conditions.
- **Baseline:** **78.2% accuracy** for the strongest centralized Neural Network baseline.
- **Stack:** Python · TensorFlow · scikit-learn

[Repository →](https://github.com/Samuel-025/federated-credit-risk-assessment)
